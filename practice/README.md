# Заказ 02 — сортировка документов склада

## Структура

| Имя | Тип | Описание |
| :--- | :---: | :--- |
| **`incoming/`** | Папка | Исходные данные. Содержит 260+ входящих документов (`.json`), включая подпапки. Файлы из этой папки **не удаляются** и не изменяются. |
| **`sorted/`** | Папка | Результат успешной обработки. Содержит копии валидных документов, разложенные по структуре `YYYY-MM/<тип_документа>/`. |
| **`quarantine/`** | Папка | Изолятор. Содержит копии проблемных файлов (неверная кодировка, битый JSON, отсутствие обязательных полей, кириллица в пути). |
| **`screens/`** | Папка | Содержит скриншоты запусков программы (`image.png`, `image-1.png` и т.д.), используемые в документации. |
| **`check_json.py`** | Скрипт | Основной исполняемый файл программы. Выполняет чтение, валидацию, копирование и логирование. |
| **`processing_log.csv`** | Файл | Журнал обработки. Хранит историю действий: имя файла, исходный путь, статус (SORTED/QUARANTINE), путь назначения, причину ошибки и время. |
| **`README.md`** | Файл | Техническое задание и описание задачи. |
| **`create.md`** | Файл | Отчет о процессе разработки. Содержит историю отладки (запуски 1–6), описание возникших проблем и путей их решения. |

## Задание

В `incoming/` лежат 260+ поступивших документов. Внутри корректного `.json` ожидаются
`document_id`, `order_id`, `document_type`, `date`, `customer`, `amount`.

Реализуйте обработку: `sorted/YYYY-MM/<тип>/`, отдельный `quarantine/` для плохих
документов и журнал `processing_log.csv`. Не теряйте исходники и не перезаписывайте
разные документы с одинаковым именем. Повторный запуск не должен плодить копии.

В данных есть одинаковые имена из разных папок, пустые файлы, JSON с ошибкой,
документы с одинаковым ID, пропущенные поля и кириллические пути.

Проверки: повторный запуск без изменения входа; две папки с `акт_001.json`;
невалидный JSON; внезапное прерывание обработки (запустите на копии).
Сдача: скрипт, журнал обработки, количество успешных/проблемных документов.
