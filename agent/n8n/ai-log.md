# Журнал ИИ: задание модуля 1

Модель: `qwen2.5:3b` · система: `Windows`

## Данные агента
uptime_s = `80716`
Мой расчёт: `0` дн. `22` ч. (как считал: `80716 / 86400 = 0.9 => 0 дней, 80716 : 3600 = 22.4 => 22 часа`)
Системная программа показала: `0:22:45`

## Запрос А — модель считает сама
Ответ 1: `около 22 часа или около 1 дня` — верно / неверно: `верно`
Ответ 2: `13 мин 51 секунду` — верно / неверно: `неверно`
Ответ 3: `2 дня и 16 часов` — верно / неверно: `неверно`

## Запрос Б — дни и часы считает n8n
Ответ 1: `более 22 часов` — верно / неверно: `верно`
Ответ 2: `уже 22 часа` — верно / неверно: `верно`
Ответ 3: `уже 0 дней и 22 часа` — верно / неверно: `верно`

## Вывод
Почему запрос Б надёжнее запроса А: `запрос Б - программа, которая умеет считать числа, запрос А прсото подбирает слова`
Что ещё в агенте лучше считать кодом, а не поручать модели: `любые вещи, где важна численная точность, т.к модель не умеет считать`
